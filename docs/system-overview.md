# Corbit — كيف يعمل النظام من A إلى Z

> منصّة سعوديّة SaaS متعدّدة المستأجرين تُمكّن أيّ شركة من إدارة محادثات واتساب الأعمال مع عملائها بدعم ذكاء اصطناعي مدرّب على بيانات الشركة.

تاريخ التوثيق: 2026-04-29

---

## 1. الأطراف الثلاثة في النظام

| الطرف | من هم | يفعلون |
|---|---|---|
| **Corbit (نحن)** | المالك التشغيلي | يشغّل المنصّة، يوافق التحويلات، يدير الدعم |
| **المستأجرون (Tenants)** | شركات تشترك | يربطون رقمهم، يضبطون الردود، يديرون عملاءهم |
| **العملاء النهائيّون** | عملاء الشركات المستأجرة | يكلّمون رقم الشركة على واتساب |

---

## 2. البنية التحتيّة

```
العميل النهائي
   └─ واتساب → 360dialog (Cloud API by Meta)
            └─ Webhook → Backend API (Laravel 12)
                        ├─ AI Engine (OpenAI GPT-4o-mini + RAG)
                        ├─ Bot Engine (Hybrid)
                        └─ MySQL DB
                              ↑
                     Frontend (Next.js 16) ← المستأجر يدخل
                     Admin Nova ← Corbit يدخل
```

3 مشاريع مستقلّة، 3 سيرفرات على Forge في الشرق الأوسط (Alibaba ECS).

---

## 3. الفلو الكامل لرسالة عميل (الجوهر)

عميل يرسل **"كم سعر الباقة؟"** لرقم شركة مستأجرة:

```
1. واتساب → 360dialog → Webhook                    (< 1 ثانية)
2. Backend يحدّد المستأجر من رقم الاستقبال
3. ينشئ/يحدّث Contact + Conversation
4. يحفظ الرسالة في DB
5. يمشي السلسلة (أوّل match يفير ويوقف):
   ├─ opt-out compliance (سياسة Meta)
   ├─ Welcome message      (لو أوّل رسالة)
   ├─ Away message          (لو خارج الدوام)
   ├─ Keyword Bot           ("سعر" يطابق ← هنا يفير)
   └─ AI Auto-Reply         (default — أيّ شي ثاني)
6. الـ Bot/AI يردّ → 360dialog → العميل يستلم
```

كلّ الـ flow ينتهي خلال **1-3 ثواني** داخل الدوام.

## 4. الـ Engine — Hybrid Bot + AI

| المسار | متى يفير | السرعة | التكلفة |
|---|---|---|---|
| **Welcome** | أوّل رسالة في محادثة | < 0.5 ثانية | مجّاني |
| **Away** | خارج ساعات العمل | < 0.5 ثانية | مجّاني |
| **Bot keyword** | الرسالة فيها كلمة مضبوطة | < 0.5 ثانية | مجّاني |
| **AI Auto-Reply** | أيّ شي ثاني (default) | 1-3 ثواني | OpenAI tokens |

### الذكاء الاصطناعي يقرأ:
- آخر 20 رسالة في المحادثة (سياق)
- ملفّات KB الخاصّة بالشركة (RAG embeddings)
- Custom Instructions (نبرة الردّ)
- Guardrails (لا يخرج عن مجال الشركة)

## 5. ما يضبطه المستأجر (Onboarding)

| القسم في الـ UI | يضبط |
|---|---|
| `/settings → ربط الواتساب` | API key 360dialog + رقم الواتساب التجاري |
| `/settings → ساعات العمل` | من-إلى لكلّ يوم |
| `/settings → الرسائل التلقائيّة` | نصّ ترحيب + نصّ غياب + نصّ انتظار |
| `/bot-builder` | بوتات keyword للأسئلة المتكرّرة |
| `/ai-center → المعرفة` | يرفع PDF/TXT عن منتجاته (مرجع للـ AI) |
| `/ai-center → النبرة` | شخصيّة AI + تعليمات مخصّصة |
| `/billing` | شحن المحفظة بتحويل بنكي |

## 6. ما يفعله Corbit

- `/super-admin` لإنشاء حسابات للمستأجرين الجدد
- **Admin Nova** للموافقة على التحويلات البنكيّة + إدارة عامّة
- مراقبة استخدام AI tokens + رصيد المحفظة + الباقات

اشتراك شهري + محفظة pay-as-you-go:

| الباقة | سعر/شهر | وكلاء | محادثات | AI credits | حملات | قوالب | بوتات | KB |
|---|---|---|---|---|---|---|---|---|
| **Starter** | 299 ر.س | 3 | 1,000 | 500 | 5 | 10 | 3 | 1 |
| **Business** | 799 ر.س | 10 | 5,000 | 3,000 | 20 | 50 | 10 | 5 |
| **Enterprise** | 1,999 ر.س | 50 | 25,000 | 20,000 | ∞ | ∞ | ∞ | ∞ |

- **الباقة:** تعطي حدود الميزات + الرسائل الشهريّة
- **المحفظة:** تخصم منها تكلفة Meta للرسائل الزائدة + AI tokens
- **إعادة الشحن:** تحويل بنكي يدوي → موافقة Admin Nova → wallet_balance يزيد

ضريبة 15% شاملة (VAT inclusive). لا توجد بوّابة دفع — تحويل بنكي فقط حاليّاً.

## 8. الأمان والعزل بين المستأجرين (Multi-Tenant)

- كلّ مستأجر له `org_id` خاص (UUID)
- كلّ صفّ في DB ينتمي لـ `org_id` معيّن
- كلّ استعلام يفلتر بـ `org_id` صراحةً
- مفاتيح 360dialog مشفّرة بـ Crypt في DB (لا تظهر بالنصّ في أيّ JSON)
- 2FA اختياري عبر SMS-OTP (mobile.net.sa)
- مستحيل مستأجر يصل لبيانات مستأجر آخر

## 11. حالة المنصّة اليوم

### ✅ يشتغل في إنتاج كامل:
- 5 مسارات auto-reply (Opt-out / Welcome / Away / Bot / AI)
- KB RAG عربي بأسعار محدّثة

## 12. خطّة العميل اليوم (مثال حيّ)

```
1. Corbit ينشئ org + admin للعميل من /super-admin
2. العميل يستلم بيانات الدخول عبر واتساب (أو SMS)
3. يدخل، يربط رقمه عبر /settings → ربط الواتساب
4. يضبط ساعات العمل + الرسائل التلقائيّة
5. (اختياري) يرفع PDF عن نشاطه في /ai-center → KB
6. (اختياري) ينشئ keyword bots للأسئلة المتكرّرة
7. يشحن محفظته بتحويل بنكي
8. ينشر رقمه على موقعه ووسائل التواصل
9. عميل يكلّمه → يردّ AI/Bot تلقائيّاً ⚡
```

## 13. ملخّص لمدير غير تقني

- Corbit = نسخة سعوديّة من Wati/Twilio لكن أرخص + أذكى للسوق المحلّي
- الميزة الفريدة: AI مدرّب على ملفّات كلّ شركة على حدة (RAG)
- كلّ شركة لها رقمها ومحفظتها وردودها ومعرفتها — معزولة تماماً
- نموذج إيراد مزدوج: اشتراك ثابت + استهلاك متغيّر = إيراد متوقّع + قابل للتوسّع
- لا تكامل بوّابة دفع حاليّاً (تحويل بنكي محلّي = لا رسوم Stripe)
- جاهز للإطلاق التجاري — بدأ تسليم العميل الأوّل اليوم
