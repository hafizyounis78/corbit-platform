1. مقدّمة

ما هو البوت في Corbit؟

البوت هو سلسلة من الخطوات المُعدَّة مسبقاً تستجيب تلقائياً لكلمات معيّنة يكتبها العميل في واتساب. مثلاً: العميل يكتب "مرحبا" → البوت يرسل ترحيب + قائمة أزرار → العميل يضغط "الدعم" → البوت يحوّل المحادثة لفريق الدعم البشري.

متى تستخدم البوت؟

الموقفاستخدم البوت؟
ردّ على أسئلة شائعة (مواعيد العمل، الأسعار، العناوين)✅ مثالي
توجيه العميل للقسم الصحيح (مبيعات/دعم/فوترة)✅ مثالي
تحصيل بيانات أوّليّة قبل تحويله لإنسان✅ مثالي
التعامل مع شكاوى حسّاسة أو معقّدة❌ حوّل لإنسان
ردود تحتاج معرفة سياق طويل وتفاوض❌ استخدم AI أو إنسان

الفرق بين البوت التقليدي والـ AI Agent

┌──────────────────────────────┬──────────────────────────────┐
│   البوت التقليدي              │   البوت + AI                  │
├──────────────────────────────┼──────────────────────────────┤
│ يردّ بنصّ ثابت معرَّف مسبقاً    │ يولّد ردّ ديناميكي من KB       │
│ مناسب للأسئلة المتوقّعة        │ مناسب للأسئلة المتنوّعة        │
│ مجّاني — لا تكلفة AI           │ بتكلفة لكلّ ردّ (نقاط AI)       │
│ يحتاج تحديث يدوي مستمرّ       │ يتحدّث تلقائياً مع تحديث KB    │
└──────────────────────────────┴──────────────────────────────┘

التوصية: ابدأ بالبوت التقليدي للـ FAQ، أضف AI Node لاحقاً لأسئلة لم تتوقّعها.

الخطوة 2: اضغط "إنشاء البوت"

ستُنقل تلقائياً لصفحة تعديل البوت. ستجد عقدة Trigger واحدة جاهزة على الـ canvas. كلّ العقد التالية تُضاف عبر زرّ "+ إضافة عقدة" أسفل الصفحة.

4. العقد التسعة — مرجع كامل

كلّ عقدة هي خطوة في التدفّق. هذا مرجع لكلّ نوع.

4.1 ⚡ Trigger — نقطة البداية

┌─────────────────────────────┐
│  ⚡ Trigger                  │
│  ─────────────────────────  │
│  كلمات: مرحبا، هلا، السلام  │
│  ↓ تذهب للعقدة التالية      │
└─────────────────────────────┘
  • متى تستخدمها: في كلّ بوت — هي البداية الإلزاميّة.
  • العدد: عقدة واحدة فقط لكلّ بوت.
  • الحقل الوحيد: قائمة كلمات مفصولة بفواصل.
  • مثال: مرحبا, هلا, السلام عليكم, hi, hello

نصائح:

  • أضف جميع المرادفات والأخطاء الإملائيّة الشائعة.
  • بدون مسافات حول الفاصلة — مرحبا,هلا لا مرحبا , هلا.
  • ضع كلمات قصيرة (1–3 كلمات). الجمل الطويلة لا تطابق غالباً.

4.2 💬 Message — رسالة نصّيّة + مرفق اختياري

┌─────────────────────────────┐
│  💬 Message                  │
│  ─────────────────────────  │
│  نصّ: مرحباً بك في خدمتنا!  │
│  مرفق: 📄 catalog.pdf       │
│  ↓                          │
└─────────────────────────────┘
  • متى تستخدمها: لإرسال أيّ ردّ نصّي ثابت — ترحيب، شرح، تأكيد، إلخ.
  • الحقول:

- النصّ: حتّى 4096 حرف (حدّ واتساب). - المرفق (اختياري): صورة / فيديو / مستند PDF (حدّ 16MB).

نصائح:

  • استخدم فواصل أسطر للوضوح بدل سطر واحد طويل.
  • ايموجي مسموحة وتُحسّن القراءة.
  • لو أرفقت ملفّاً، اسم الملفّ الأصلي يصل للعميل (مثلاً كتالوج-2026.pdf).

4.3 🔘 Buttons — قائمة خيارات

┌─────────────────────────────┐
│  🔘 Buttons                  │
│  ─────────────────────────  │
│  نصّ: اختر الخدمة:          │
│   ┌──────────────────────┐  │
│   │ 1. الدعم الفنّي      │  │
│   ├──────────────────────┤  │
│   │ 2. المبيعات          │  │
│   ├──────────────────────┤  │
│   │ 3. الفوترة           │  │
│   └──────────────────────┘  │
│       ╱   │   ╲             │
│      ▼    ▼    ▼            │
│  (3 عقد تالية، واحدة لكلّ زرّ)│
└─────────────────────────────┘
  • متى تستخدمها: لتقديم خيارات محدّدة للعميل (max 3 لواتساب).
  • الحقول:

- النصّ: سؤال يظهر فوق الأزرار. - الأزرار: قائمة نصوص (أقصى 20 حرف لكلّ زرّ).

  • الإخراج: كلّ زرّ يذهب لعقدة مختلفة في الـ flow.

نصائح:

  • 3 أزرار أقصى — هذا حدّ واتساب، الزرّ الرابع يُتجاهَل.
  • النصّ القصير على الزرّ أوضح ("الدعم" بدل "اضغط هنا للدعم الفنّي").
  • لا تستخدم Emoji في نصّ الزرّ — واتساب يرفضه أحياناً.

4.4 ✍️ Input — التقاط ردّ العميل

┌─────────────────────────────┐
│  ✍️ Input                    │
│  ─────────────────────────  │
│  سؤال: ما رقم طلبك؟         │
│  متغيّر: {{order_id}}        │
│  ↓ يحفظ الردّ ويتابع          │
└─────────────────────────────┘
  • متى تستخدمها: لطلب معلومة محدّدة من العميل (رقم طلب، إيميل، رقم تواصل).
  • الحقول:

- السؤال: نصّ يُرسل للعميل. - اسم المتغيّر: لحفظ الإجابة (تستخدمها عقد لاحقة).

نصائح:

  • استخدم متغيّر بالإنجليزي ومختصر (order_id لا "رقم_الطلب").
  • يمكن استدعاء المتغيّر في عقد لاحقة بصيغة {{order_id}}.

4.5 🔀 Condition — تفريع شرطي

┌─────────────────────────────┐
│  🔀 Condition                │
│  ─────────────────────────  │
│  الشرط: {{score}} >= 80     │
│       ╱         ╲           │
│      ▼ نعم      ▼ لا        │
│   (عقدة A)   (عقدة B)       │
└─────────────────────────────┘
  • متى تستخدمها: لتفريع المسار بناءً على قيمة متغيّر سابق.
  • الحقل: تعبير منطقي بسيط مع متغيّرات {{var}}.

أمثلة على التعابير:

التعبيرالمعنى
{{score}} &gt;= 80إذا score أكبر من أو يساوي 80
{{country}} == "SA"إذا الدولة هي SA
{{order_id}} != ""إذا كتب العميل رقم طلب

نصائح:

  • استخدم القوسين {{}} حول المتغيّر دائماً.
  • النصوص بعلامتي تنصيص مزدوجتين "value".
  • لو الشرط معقّد، استخدم AI Node بدل Condition.

4.6 🤖 AI — ردّ ذكي من قاعدة المعرفة

┌─────────────────────────────┐
│  🤖 AI                       │
│  ─────────────────────────  │
│  Model: gpt-4o-mini         │
│  Knowledge Base: ✓           │
│  Confidence threshold: 0.7  │
│  Auto-escalate: ✓            │
│  ↓ يولّد ردّ ديناميكي         │
└─────────────────────────────┘
  • متى تستخدمها: لأسئلة لم تتوقّعها مسبقاً، يحتاج فيها العميل ردّ مخصّص.
  • الحقول:

- Model: محرّك AI (افتراضي gpt-4o-mini — سريع ورخيص). - Knowledge Base: تفعيل البحث في KB قبل الردّ. - Conversation Context: تمرير سياق المحادثة السابقة. - Confidence Threshold: الحدّ الأدنى لثقة الردّ (0.7 = جيّد). - Auto-escalate: تحويل تلقائي للإنسان لو الثقة أقلّ من threshold.

شروط مهمّة قبل استخدامها:

  1. ارفع KB من صفحة "AI Center" → "Knowledge Base" (PDF أو TXT).
  2. تأكّد من رصيد AI في صفحة "الفوترة" — كلّ ردّ يستهلك نقاطاً.
  3. اختبر بـ Test Mode قبل النشر.

4.7 🔄 Transfer — تحويل لفريق بشري

┌─────────────────────────────┐
│  🔄 Transfer                 │
│  ─────────────────────────  │
│  الفريق: الدعم الفنّي         │
│  ↓ تنتهي مهمّة البوت          │
└─────────────────────────────┘
  • متى تستخدمها: لتحويل المحادثة من البوت لموظّف بشري.
  • الحقل: اسم الفريق (مُعرَّف مسبقاً في صفحة "الفِرق").

نصائح:

  • عرّف الفرق أوّلاً من Settings → Teams (مثلاً: "دعم فنّي"، "مبيعات"، "فوترة").
  • بعد التحويل، البوت يتوقّف والمحادثة تظهر للموظّفين في الـ Inbox.
  • العميل يستلم رسالة "تمّ تحويلك لموظّف، سيردّ عليك خلال دقائق".

4.8 🔌 API — استدعاء HTTP خارجي

┌─────────────────────────────┐
│  🔌 API                      │
│  ─────────────────────────  │
│  URL: https://api.x.com/    │
│  Method: GET                 │
│  Headers: Authorization: ... │
│  ↓ يحفظ الردّ ويتابع          │
└─────────────────────────────┘
  • متى تستخدمها: للاستعلام من نظامك الداخلي (CRM، نظام طلبات، إلخ).
  • الحقول: URL + Method (GET/POST) + Headers + Body.

أمثلة على الاستخدام:

  • جلب حالة طلب من نظام داخلي.
  • التحقّق من نقاط الولاء.
  • إرسال إشعار لنظام تذاكر.

ملاحظة فنّيّة:

  • الـ API node متاح لكن يحتاج إعداد فنّي (Headers + Body templating).
  • لو احتجت ربط معقّد، تواصل مع فريق دعم Corbit.

4.9 🏁 End — إنهاء التدفّق

┌─────────────────────────────┐
│  🏁 End                      │
│  ─────────────────────────  │
│  (لا حقول)                  │
│  ينهي البوت                 │
└─────────────────────────────┘
  • متى تستخدمها: في نهاية كلّ مسار في الـ flow.
  • بدون حقول — مجرّد إشارة "البوت انتهى".

نصائح:

  • كلّ مسار في الـ flow يجب أن ينتهي بـ End أو Transfer.
  • إذا نسيت End، البوت سيتوقّف "في الهواء" والعميل يحسّ إنّ المحادثة عالقة.

الهدف

المخطّط

┌─────────────────────────────┐
│  ⚡ Trigger                  │
│  كلمات: مرحبا، هلا           │
└──────────────┬──────────────┘
               │
               ▼
┌─────────────────────────────┐
│  💬 Message                  │
│  "مرحباً بك في متجرنا! 🌹    │
│   اطّلع على آخر العروض:      │
│   1. خصم 20% على الكتب       │
│   2. شحن مجاني للطلبات       │
│   3. تواصل واتساب: 920000... │

خطوات البناء

1. اضغط "+ بوت جديد" → املأ:

  • الاسم: "بوت الترحيب"
  • الكلمة المفتاحيّة: مرحبا, هلا, السلام عليكم, hi, hello
  • تفعيل AI: ✗ (غير ضروري لهذا البوت)

2. بعد الإنشاء، ستجد عقدة Trigger جاهزة. اضغط "+ إضافة عقدة" → اختر Message.

3. اضغط على عقدة Message المُضافة، وفي الـ sidebar اليمنى:

  • النصّ:

``` مرحباً بك في متجرنا! 🌹

اطّلع على آخر العروض: 1. خصم 20% على الكتب 2. شحن مجاني للطلبات فوق 200 ريال 3. تواصل واتساب: 920000000

أهلاً بك مرّة أخرى 🌸 ```

  • المرفق (اختياري): ارفع catalog.pdf

4. اضغط "+ إضافة عقدة" → اختر End. (سيُربط تلقائياً بـ Message السابقة.)

5. اضغط 💾 حفظ أعلى الصفحة.

6. اضغط ▶ Test لاختبار البوت قبل النشر (راجع القسم 8).

7. عند الرضى، اضغط [نشر] في الـ bottom bar.

خطوات البناء

0. تجهيز KB (إلزامي قبل البدء)

  • من AI Center → Knowledge Base، ارفع ملفّاً (PDF / TXT) يحوي:

- أسئلة شائعة + إجاباتها. - معلومات المنتجات / الخدمات. - سياسات الإرجاع / الشحن.

  • تأكّد من رصيد AI في الفوترة.

1. أنشئ بوت جديد:

  • الاسم: "بوت ذكاء اصطناعي"
  • الكلمة المفتاحيّة: سؤال, استفسار, أبغى أعرف
  • تفعيل AI: ✓

2. أضف Message ترحيب بسيط.

3. أضف AI Node واضبط:

  • Model: gpt-4o-mini (الافتراضي مناسب)
  • Knowledge Base: ✓ مفعّل
  • Confidence Threshold: 0.7
  • Auto-escalate: ✓ مفعّل

4. أضف Transfer للفريق ("دعم فنّي") — سيُستخدم عند ثقة منخفضة.

5. أضف End للمسار عند ثقة عالية.

6. مهمّ: AI Node + Auto-escalate يتعاملان مع التفريع تلقائياً — لست بحاجة لـ Condition Node منفصلة.

7. احفظ + اختبر بأسئلة من KB + أسئلة خارج KB.

كيفيّة الاختبار

  1. اكتب الكلمة المفتاحيّة (مثلاً "مرحبا") واضغط إرسال.
  2. شاهد ردّ البوت يظهر فوراً.
  3. لو فيه أزرار، اضغط أحدها لمتابعة التدفّق.
  4. لو فيه Input، اكتب نصّاً للاختبار.
  5. تابع حتّى تصل لـ End أو Transfer.

ما تتأكّد منه

  • ✅ الترحيب يظهر بشكل صحيح (بدون أخطاء إملائيّة، Emoji تظهر).
  • ✅ الأزرار تنقل للعقدة الصحيحة.
  • ✅ AI ينتج ردّاً منطقيّاً (للبوتات الذكيّة).
  • ✅ Transfer يصل للفريق الصحيح.
  • ✅ لا توجد عقد "معلّقة" بدون End.

9. نشر البوت

حالات البوت

الحالةالمعنى

Testing (اختبار)متاح للاختبار الداخلي فقط

نشر البوت

من الـ bottom bar، اضغط الزرّ [نشر]. يتحوّل لـ [إيقاف] بمجرّد النشر.

Cooldown — مدّة الانتظار

الـ Cooldown يمنع تكرار البوت لنفس العميل خلال فترة محدّدة.

مثال:

  • Cooldown = 24 ساعة.
  • العميل كتب "مرحبا" الساعة 10 صباحاً → البوت ردّ.
  • العميل كتب "مرحبا" الساعة 11 صباحاً (نفس اليوم) → البوت لا يردّ (التزاماً بالـ cooldown).
  • العميل كتب "مرحبا" الساعة 11 صباحاً اليوم التالي → البوت يردّ مرّة أخرى.

التوصيات:

  • 24 ساعة للبوت الترحيبي — تجنّب الإزعاج.
  • 0 ساعات للبوت الـ FAQ — العميل قد يحتاج إعادة الإجابة.
  • 72 ساعة الحدّ الأقصى (سياسة Meta).

إيقاف مؤقّت

لإيقاف البوت دون حذفه، اضغط [إيقاف]. يتحوّل لحالة Draft ولا يستجيب. تستطيع إعادة تفعيله متى شئت.

10. استكشاف الأخطاء

المشكلة: البوت لا يردّ على العملاء

التحقّق:

  1. هل البوت في حالة Published؟ (راجع الـ bottom bar)
  2. هل الكلمة اللي كتبها العميل مطابقة تماماً لإحدى كلمات Trigger؟ (افحص الإملاء + المسافات)
  3. هل العميل داخل الـ cooldown من محادثة سابقة؟ (انتظر 24 ساعة أو قلّل cooldown)
  4. هل رقم الواتساب متّصل؟ (راجع Settings → WhatsApp)

المشكلة: AI Node يرفض الردّ

التحقّق:

  1. هل ارفعت KB من AI Center → Knowledge Base؟
  2. هل عندك رصيد AI كافٍ؟ (راجع الفوترة)
  3. هل Confidence Threshold عالي جداً؟ (جرّب 0.5 بدل 0.7)

المشكلة: Transfer لا يحوّل للفريق

التحقّق:

  1. هل اسم الفريق صحيح في عقدة Transfer؟ (يجب يطابق اسماً مُعرَّفاً في Settings → Teams)
  2. هل الفريق فيه أعضاء؟ (الفريق الفارغ لا يستلم تحويلات)

المشكلة: المرفق يصل بدون اسم (untitled)

التحقّق:

  • هذه المشكلة أُصلحت في تحديث 2026-05-17. تأكّد إنّ منصّتك مُحدَّثة.

المشكلة: الأزرار لا تظهر للعميل

التحقّق:

  1. هل عدد الأزرار ≤ 3؟ (واتساب يرفض الأكثر)
  2. هل نصّ الزرّ ≤ 20 حرف؟ (الأطول يُقصّ)
  3. هل ضمنت Emoji في نصّ الزرّ؟ (احذفها)
