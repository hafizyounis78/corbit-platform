## 5. Multi-tenant rules (CRITICAL)

Every fix in this codebase must respect:

1. **Every API endpoint** uses `$this->getOrgId()` from `BaseController`. Never reach across orgs.
2. **Every DB query** in services takes `$orgId` and filters with `where('org_id', $orgId)`. Models with `BelongsToOrganization` trait do this implicitly — verify before relying.
3. **Settings tables** with per-org rows: `org_settings`, `conversation_settings`, `sla_settings`, `sms_settings`, `business_hours`, `auto_messages`, `notification_preferences`, `whatsapp_numbers`, `bots`, `bank_accounts` (NB: bank_accounts is platform-wide — Corbit's banks for receiving transfers, not per-org).
4. **WhatsApp sends:** `WhatsAppService::sendText/Template/Media` take `?string $orgId = null`. Pass org_id for tenant flows. Pass null only for Corbit-internal (welcome notifications, payment confirmations).
